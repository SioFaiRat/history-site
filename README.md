# ★ Города-герои

Интерактивный учебный сайт о **13 городах-героях** Великой Отечественной войны: карта обороны, хронология, герои, памятники, архивные документы.

## Стек

- React 18 + Vite
- react-router-dom (маршрутизация)
- react-leaflet / Leaflet (интерактивная карта)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/
```

## Структура проекта

```

│   └── images/                 # фото памятников, сканы документов (заполняет дизайнер)
└── src/
    ├── main.jsx                # инициализация приложения + стили Leaflet
    ├── App.jsx                 # маршруты: / , /cities/:cityId , /timeline , /compare
    ├── styles/
    │   └── global.css          # общая тема (цвет «Золотой звезды», шрифт, карточки)
    ├── components/
    │   ├── Layout.jsx          # шапка с навигацией, подвал с источниками
    │   ├── HeroMap.jsx         # карта: 13 звёзд-маркеров, попапы, переключатель слоёв
    │   └── CityCard.jsx        # карточка города для сетки на главной
    ├── pages/
    │   ├── HomePage.jsx        # главная: введение + карта + сетка городов
    │   ├── CityPage.jsx        # раздел города: История / Герои / Памятники / Документы / Цифры и факты
    │   ├── TimelinePage.jsx    # общая хронология войны по всем городам
    │   └── ComparePage.jsx     # сравнение: дни обороны, число героев (таблица + бары)
    ├── data/                   # «база данных» — плоские JS-массивы по схемам ниже
    │   ├── cities.js           # City: id, name, modernName, coordinates, defenseStart/End, awardDate, …
    │   ├── heroes.js           # Hero: id, name, birthPlace, rank, awardDate, biography, cityId, branch
    │   ├── monuments.js        # Monument: id, name, cityId, coordinates, description, photoUrl

    │   └── events.js           # Event: id, title, cityId, date, description
    └── services/
        └── pamyatNaroda.js     # каркас клиента «Память народа» / «Подвиг народа» (TODO: прокси)
```

## Схемы данных (как обсуждали)

| Сущность | Поля |
|---|---|
| **City** | id, name, modern_name, coordinates, defense_start, defense_end, award_date, description |
| **Hero** | id, name, birth_place, rank, award_date, biography, city_id (+ branch — род войск для фильтра) |
| **Monument** | id, name, city_id, coordinates, description, photo_url |
| **Document** | id, title, archive_source, scan_url, city_id, date |
| **Event** | id, title, city_id, date, description |

Сейчас данные живут в `src/data/*.js` — это удобно для старта. Когда наполним базу, можно переехать на SQLite/Postgres без изменения интерфейсов функций-геттеров (`getCityById`, `getHeroesByCity`, …).

## Карта

- `react-leaflet`, OSM-тайлы (бесплатно).
- Два слоя в LayersControl: современный и исторический (границы СССР 1941–1945). Для исторического нужно подготовить тайлы через mapwarper.net и подставить URL в `HeroMap.jsx` (помечено TODO).
- Маркеры — золотые ★; клик → попап с краткой информацией и ссылкой на `/cities/<id>`.

## Источники данных

- [Память народа](https://pamyat-naroda.ru) — наградные листы, боевые документы, пути подразделений
- [Подвиг народа](https://podvignaroda.ru) — база наградных документов
- [ОБД Мемориал](https://www.obd-memorial.ru) — погибшие и пропавшие без вести
- Сайты городов (Волгоград, Севастополь, Минск) — местные мемориальные разделы
- Росархив — указы о присвоении звания

⚠️ Публичного API у этих сайтов нет — понадобится свой прокси (парсинг поисковых страниц). Интерфейс клиента уже подготовлен в `src/services/pamyatNaroda.js`.
